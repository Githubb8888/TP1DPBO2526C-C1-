Design Explanation and Code Flow
This program was developed to manage Cinema (Bioskop) data using Object-Oriented Programming (OOP) concepts.

- Class Design: There is only 1 main class, Movie, which represents the cinema data. This class contains 4 basic attributes: id, title, genre, and price. Specifically for the Web (PHP) implementation, 1 additional mandatory attribute, image, was added to store the local file path of the image.

- Data Storage: The collection of objects is managed using an array/list of objects data structure in memory (Vector in C++, ArrayList in Java, and List in Python). In the Web (PHP) version, data storage utilizes $_SESSION since the use of a database is strictly prohibited.

- Features & Flow: The program provides a menu-driven interface (Terminal/CLI for C++, Java, Python, and an HTML Form for PHP). The mandatory features implemented include:
1. Add Data: Create and append a new object.
2. Show Data: Display all currently stored objects.
3. Update Data: Modify the attributes of an object based on its unique ID.
4. Delete Data: Remove an object from memory based on its ID.
5. Search Data: Find and display a specific object using its ID.
